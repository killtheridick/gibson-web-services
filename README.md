# Gibson Web QA & Automation

Practical website QA, small web fixes, and lightweight Python automation for small businesses.

## Services

### Website QA Audit — $50

A public, read-only website review with a prioritized report covering issues such as:

- page structure and heading problems
- missing or empty image alt text
- duplicate or weak page titles
- broken or suspicious links
- basic accessibility and usability issues
- sitemap and robots.txt checks where relevant

No login access is required, and no changes are made during the audit.

### Small Python / CSV Automation — $50–$150

Fixed-scope automation for repetitive data tasks, including:

- CSV cleanup and deduplication
- header and field normalization
- simple data transformation
- repetitive file-processing workflows
- small Python utilities with usage instructions

### Small Website Fixes — $75–$200

Narrow, authorized fixes for issues such as:

- heading structure
- alt text
- page-title cleanup
- simple HTML/CSS defects
- small accessibility improvements

Website changes are made only with explicit authorization and a defined scope.

## How it works

1. Send the public website URL or describe the task.
2. Scope and price are confirmed before work begins.
3. Payment is handled securely through Stripe.
4. The agreed report, files, or fix are delivered.
